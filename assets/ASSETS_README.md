## Icon Design Guidelines

### Color Palette
- Primary: Purple/Violet (#8B5CF6)
- Accent: Blue (#6366F1)
- Glow effect with gradient

### Design Concept
Option 1: **Pulse Circle**
- Concentric circles radiating outward
- Gradient from purple to blue
- Subtle glow effect

Option 2: **Emotion Wave**
- Abstract wave/pulse pattern
- Multi-color gradient representing moods
- Modern, minimal aesthetic

Option 3: **Connected Dots**
- Multiple dots (representing people) with pulse effect
- Lines connecting them
- Represents global connection

### Style
- Modern, minimal, flat design
- No text in icon
- Recognizable at small sizes
- Stands out on both light and dark backgrounds
